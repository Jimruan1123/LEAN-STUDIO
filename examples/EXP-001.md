# EXP-001｜装配图谱最小实验

目的：证明同一图谱支持自由零件创建及连接、标准模板参数变化、模块增删与 BOM 同源。第一版只验证抽象数据流，不含真实几何或连接件。以 40×40 示例型材和 28 mm 示例管材区分接口族；所有长度为示例，不是下料长度。工作台模板只包含抽象框架和可选挂板，不代表工程设计。

运行：`python -m unittest discover -s tests -v` 与 `python -m engine.prototype`。
下一实验：补齐真实零件图、局部坐标接口、连接件及合法重叠；生成真实可转动视图；在同一引擎分别构建精益管非标架与铝型材标准台。用户模型到位后并行启动逆向导入。
