# ADR-005 | 三级设计资源库与模型参数化
状态：产品方向确认；V0.3-A 首个工作桌模型试点，浏览器 DOM 与离线图谱验证通过，线上 WebGL 待验收。

## 三种互补设计路径
- 模型库 + 参数：常规复用、快速尺寸变体；无需 AI 对话。
- AI 自然语言：从零创造、复杂结构改造、跨模型/模块组合。
- 自由编辑：局部精细调整；保留结构、BOM 和连接关系。三者共享图谱及操作 API，不另建引擎。

## 资源分层
L1 PartDefinition：参数化型材与固定标准件、接口、来源、版本、验证状态。
L2 ModuleDefinition（规划）：可独立插入的功能子图谱（搁板、挂板、抽屉、脚轮等），含参数与外部装配接口，不能只保存 GLB。
L3 ModelDefinition：完整可编辑装配模板，含 model_id/revision、类别、默认参数、单位/范围、参数到图谱的映射、来源、验证状态及兼容零件版本。可由 AI 或人工自由设计保存为模型候选，但必须明确可配置参数、测试依赖关系及批准版本；未审核的样例不得冒称正式标准模型。
