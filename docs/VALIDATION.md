# 验证计划 V0.1

所有 Gate 默认 OPEN；通过需记录输入、环境、命令、实际输出、证据、版本、已知问题。概念实验与真实工程验收区分。

| ID | 路线 | 实验与验收标准 | 当前状态 |
|---|---|---|---|
| E01 | 基础 | 28 mm 精益管与 40×40 型材定义、接口版本、兼容/不兼容连接、缺值报告 | OPEN |
| E02 | 自由 | 从空白图谱添加零件并连接成流利架；无完整产品模板；局部修改、增删节点，BOM 同步 | OPEN |
| E03 | 标准 | 工作台 1500→1800、宽高变化、脚轮替换保持台面高度、配件增删；无关实例稳定 | OPEN |
| E04 | 混合 | 标准台添加非标侧架，调整主体尺寸后处理依赖/冲突，保存新模板并复现 | OPEN |
| E05 | 逆向 | 导入用户提供的原始装配，统计实体/实例；已知零件匹配，未知件保留；恢复关系需标置信度；与原始 BOM/尺寸核对 | OPEN |
| E06 | 工程 | 真 CAD STEP 与视图、实例数量、尺寸、BOM 一致；干涉检查区分合法重叠 | OPEN |
| E07 | 交互 | 真实浏览器旋转缩放、选件、连接、爆炸、保存重载、撤销，记录屏幕与控制台 | OPEN |
| E08 | 规则 | 超跨度、缺料号、接口不匹配、载荷未知均返回状态；不将未校核误报通过 | OPEN |
| E09 | AI | 自然语言转工具操作，预览 diff；非法操作失败且状态不变；重复执行可重现 | OPEN |
| E10 | 现场 | 工程人员确认下料、装配、成本、载荷/稳定性；实际样件或制造验证 | OPEN |

建议 3–5 个自有/有权使用模型：工作台、流利架、周转车、复杂非标工装；优先原始装配/STEP，补充 BOM、尺寸、连接件系列、现场功能。导入测试记录零件识别覆盖率、未知件数、装配边正确率（有人工真值才计算）、尺寸误差；阈值须由实际图纸公差与工程要求确定。E03 测试必须区分外形、净切割长度与总高度。不得以简单轴测示意冒充实际 CAD。

## 首期验收范围调整（ADR-003）
首期 E01/E02 等涉及精益管的用例改为 20/30/40 方形铝型材及配件；E02 自由设计为铝型材框架，E03 SOP 为铝型材工作台，E05 优先铝型材装配样本。原 28mm 管材测试保留为历史或后续扩展，不阻塞当前版本。具体见 [ADR-003](ALUMINUM-FIRST.md)。所有未实际验证项仍 OPEN。
