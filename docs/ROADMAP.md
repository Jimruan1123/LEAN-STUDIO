# 项目章程与路线 V0.1

## 目标与范围
- 双主线：A 通用精益结构自由设计（自然语言、拖拽、草图与参数）；B SOP 产品配置（尺寸、配件、版本变体）。共同引擎，均为必验能力。
- 两条融合路线：C 标准产品继续自由修改并保存为新模板；D 已有装配体导入、拆解、识别、重建与改造。
- 材料：首期 28 mm 精益管与 40×40 铝型材（示例规格，实际供应商系列须核实），后续扩展。候选产品：工作台、FIFO 流利架、周转车、线边超市、设备框架、Karakuri。
- 交付：可交互 3D、独立零件、装配关系、工程 STEP、BOM、切割清单、装配 SOP、工程校核状态、配置与修订历史。不能以渲染效果替代工程正确性。

| Gate | 目标 | 主执行环境 | 出口 |
|---|---|---|---|
| G0 | 调研复用、来源登记、样本与数据契约 | Chat/Work | 可复用/仅参考/待授权矩阵；样本清单 |
| G1 | 两类零件及接口、自由装配、BOM | Chat→Codex | 可重复图谱实验、接口检查、真实3D验证 |
| G2A | 自由构建非标结构 | Chat→Codex | 无完整模板也能构建并局部修改 |
| G2B | SOP 产品参数化配置 | Chat→Codex | 1500→1800、模块增删、总高不变 |
| G2C | 混合设计 | Chat→Codex | 标准模板可自由扩展并保存新模板 |
| G2D | 现有模型逆向 | Chat→Codex | 读取装配、识别、带置信度重建 |
| G3 | CAD/装配/预览集成 | Codex | STEP、图谱、BOM 同源且一致 |
| G4 | AI 工具及交互 | Codex | 可审计操作、撤销、版本比较、人工确认 |
| G5 | 工程与业务验证 | Work+工程人员 | 实际目录、受力、制造、现场验收证据 |
| G6 | 知识库扩充与企业应用 | Work/Codex | 标准产品及方案库、受控采购数据 |

G2A/B/C/D 并行设计、分开验收；不能用 B 的通过代替 A。Chat 首轮验证数据结构及可展示原型；涉及 WebGL、CAD 内核的真实测试转本地 Codex。Work 负责资料研究、知识整理与协调。未验证 Gate 标记 OPEN；允许部分通过但不得宣称全部完成。
