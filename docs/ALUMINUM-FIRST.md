# ADR-003｜方形铝型材优先
2026-11-26，用户确认。首期聚焦 20×20、30×30、40×40 mm 方形槽式铝型材；28 mm 精益管延后，已有原型与测试保留作为历史基线，不作为当前验收前置条件。不删除材料扩展接口。建议先 40 系列验证完整流程，再扩展 20/30；三系列均为首期目标。
双主线不变：从空白场景自由搭建，以及 SOP 标准产品配置；支持混合设计。Web/YIDA 轻量装配与参数编辑、外部零件生产、成熟开源能力优先继承继续有效。

## V0.2-B 最小纵向切片（规划）
1. 截面：20/30/40 方形 T-slot，每系列先选一个真实有依据的截面版本。以授权供应商图纸或独立定义建模；区分槽宽、截面、料号、连接件兼容族。同外宽不等于兼容。不默认某槽宽或承载。
2. 首批零件：可变长度型材、固定角码、T 型螺母、螺栓、端盖；固定地脚、脚轮、板材及搁板随后按案例补齐。跨系列连接仅通过有证据的适配件。
3. Web：沿轴向拉伸/裁短保留截面；板材长宽厚独立参数；固定件移动、旋转、复制、吸附；连接位置与 BOM 同步。正式采用 Three.js/GLTFLoader，保留 V0.2-A 回归；不继续扩大 Canvas 临时渲染器。
4. A 自由设计：空白搭建方形框架，至少包含直角连接、角码及紧固件实例；添加/删除/局部修改，保存与重新打开。
5. B 标准设计：40 系列工作台 1500→1800 mm，台面、横梁及配件联动；验证高度保持、截面保持、BOM 和连接关系一致；超跨度标记待工程复核。
6. C 混合设计：添加侧架或搁板、保存新版本；检查参数修改不静默丢失非标件。
7. 20/30 扩展：同一接口规范和生成器加载独立截面与连接件定义，分别构建小框架，错误跨系列配对拒绝。
8. 外部资产：GLB+JSON+可选 STEP/截面数据，至少两种生产工具输出的零件通过尺寸/坐标/接口核验；供应商资产须先确认许可。
验收状态全部 OPEN。已有精益管实验不作废，但不继续扩充。工程承载、实际采购与制造仍须专业校核。宜搭接入探针并行，未验证不宣称可部署。npm/DNS 与浏览器实际导航阻塞沿用 V0.2-A 记录，必要时转本地 Codex。
