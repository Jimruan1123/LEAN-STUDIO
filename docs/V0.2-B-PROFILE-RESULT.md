# V0.2-B | 首轮开源截面继承
已读取 NopSCADlib 上游参数和截面生成源码，提取方形截面独立生成器，在 OpenSCAD 2021.01 实测 20/30/40 各 500 与 800 mm，6 个模型封闭且各单一连通实体、尺寸正确；两长度截面差面积小于 0.01 mm²（显示精度下 0），500 mm GLB 米制 Y-up 尺寸通过重载检查。源文件与实测汇总在 research/upstream/nopscadlib-profile-probe/。完整本轮 ZIP 在聊天附件，含 GLB、截面 JSON、part.json、STL、生成及转换代码。

未完成：真实供应商截面、配件、自动吸附、完整装配、Three.js/YIDA、采购和承载认证。所有资产 NEEDS_REVIEW，V0.2-B 整体门仍 OPEN。下一轮优先同一兼容族 4040 角码、T 型螺母、螺栓及端盖，再验证直角框架。28mm 精益管延后。
