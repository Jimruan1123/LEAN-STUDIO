# 四类资源接入

| 来源 | 接入内容 | 控制 |
|---|---|---|
| GitHub 成熟应用 | CAD、装配、型材、UI、BOM 算法与测试案例 | 固定 commit；查许可证、依赖、活跃度；明确复用/参考 |
| MISUMI 等供应商 | STEP/DXF、截面、料号、规格、安装、载荷、兼容信息 | 按产品/地区确认条款；未经授权不批量下载、改造或再发布 |
| 企业已有工装 | 有权使用的装配、BOM、图纸、案例及 SOP | 分类分级，原件只读，敏感模型受控，解析后保留证据 |
| 自主建模 | 参数化管材/型材、接口、通用配件、非标结构 | 独立创作；尺寸来源可追溯；工程属性缺失显式标记 |

流程：登记 → 权限确认 → 原始资源隔离 → 解析/人工摘录 → 单位与坐标标准化 → 识别和接口标注 → 工程/许可复核 → 发布版本化零件/规则/模板。未确认授权的原件、供应商缓存、价格和敏感数据不进入 GitHub，即使私有也不自动获得授权。不得绕过登录、验证码或下载限制。

来源记录字段：source_id、origin、url_or_local_id、revision、retrieved_at、license、allowed_use、redistribution、geometry_hash、evidence、review_status、reviewer。未知许可=待审，不等于可用。不同供应商同名尺寸不意味着接口兼容。

逆向导入：优先 STEP/XCAF 或原始装配；保留实例层级及局部坐标；分离独立件、识别重复几何、匹配零件、生成候选连接；人工确认无法推断的参数、载荷及设计意图。网格导入只能恢复有限几何语义，不自动认证工程属性。
