# LEAN-STUDIO V0.2-C | 4040 assembly kit research probe

This is an offline geometry/assembly experiment, not a released web editor. All parts are NEEDS_REVIEW. E4040t is a distinct profile from E4040, matched to the upstream E40 bracket default. Profile source adapted from NopSCADlib (Chris Palmer 2020, GPL-3.0-or-later), upstream blobs b3e7e2657c3e5c36ff3948c828d8e0f3940c2bba and 5aa7c8e05a79c1c88bc465cc65a563613a714229. Bracket nominal data: extrusion_brackets.scad blob 21baeffd1aa4d14a34153c1556cf75f43f3e7927; extrusion_bracket.scad acaad2c367f601c05dd9d36d7edae175f37b4363. Nut and screw data: nuts.scad 4b69c49fbe8122c3b522eb94d7e6a286e4929047; screws.scad b5c68f814705ec3eaa41b804c8ed6399c12dd91b. All links at https://github.com/nophead/NopSCADlib/tree/master/vitamins. Bracket is simplified based on nominal dimensions; nut has no spring ball/threads, screw has no threads/socket, end cap is a flat visual proxy with no retention feature. M8×12 is a prototype choice, not validated purchase specification. No supplier CAD copied.

Run `python build_kit.py` using OpenSCAD, CadQuery, NumPy, trimesh and Shapely. `python preview.py` (Matplotlib) renders generated meshes. Results: 15 checks, including profile invariant, local clearance checks, eight mating anchors each configuration, 28 instances, 36 edges, 500→800 beam length, right subtree translation, GLB/JSON round trips. Local clearance is NOT global collision checking, thread engagement or strength. The fixed frame recipe computes poses; it is NOT a generic interactive snapping solver. GLB scene has 28 named nodes; part asset packages have metadata, not full supplier/engineering attributes. Offline GPL research source isolated; integrated distribution obligations require review before release. Profile generator in this package is only validated at series=40; 20/30 remain previous experiment. No Three.js or YIDA execution in this round.
